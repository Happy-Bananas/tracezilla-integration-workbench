# Choose an implementation

Choose a platform based on the environment in which the integration will be
owned and operated.

| Situation | Suggested example |
|---|---|
| Visual automation with minimal code | [Make.com](./platforms/make-catalog-comparison.html) |
| Existing PHP or Laravel application | [Laravel](./platforms/laravel-catalog-comparison.html) |
| Portable JavaScript service | [TypeScript and Docker](./platforms/typescript-docker-catalog-comparison.html) |
| Portable Python script | [Python and Docker](./platforms/python-docker-catalog-comparison.html) |

The current Make.com, TypeScript, and Python examples perform a read-only
catalog comparison. Laravel currently includes additional catalog, inventory,
and order workflows. That difference in coverage does not make Laravel a
requirement or the canonical definition.

Open [Laravel](./laravel-reference.html), [Make.com](./make.html),
[TypeScript](./typescript.html), or [Python](./python.html) to find its examples
and reference material.
