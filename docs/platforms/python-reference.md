# Python reference

The example is a small CLI using the Python standard library, environment
configuration, and mocked client tests. Its source lives under
`examples/python-catalog-comparison/`.

Use the root `compose.yaml` to build and run it. Configuration uses the shared
Shopify and tracezilla variables plus `HTTP_TIMEOUT_SECONDS`.
