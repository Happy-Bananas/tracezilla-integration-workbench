# TypeScript reference

The example is a small Node.js CLI using built-in `fetch`, typed API-boundary
objects, environment configuration, and mocked client tests. Its source lives
under `examples/typescript-catalog-comparison/`.

Use the root `compose.yaml` to build and run it. Configuration uses the shared
Shopify and tracezilla variables plus `HTTP_TIMEOUT_MS`.
