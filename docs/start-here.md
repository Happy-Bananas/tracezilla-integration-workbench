# Getting started

Begin with the integration need, then choose the implementation that fits the
customer and operating environment.

## Recommended path

1. Read the [Project Scope](./project-scope.html).
2. Read the [Integration Overview](./integration-overview.html).
3. [Choose an Implementation](./choose-implementation.html).
4. Complete the platform-neutral [Setup](./setup.html).
5. Open your platform and start with its read-only **Compare Catalogs** example.

The API behavior, terminology, and mapping decisions are platform-neutral.
Laravel, Make.com, TypeScript, and Python are implementation choices.
